{# ── How to read the results (first, before the architecture) ── #}

{% trans "Read this first" %}

{% trans "How to read the results" %}

  • {% trans "All evidence is computational" %} {% trans "— except PDB co-crystal binders (experimental co-crystallization) and direct ChEMBL entries (measured bioactivity). Everything else is predicted, not confirmed." %}
  • {% trans "Absence of a value is not absence of the property." %} {% trans "EC = 0 can mean the protein has no characterized enzymatic activity, or that the pipeline found insufficient homology, or that the tool was not configured for that organism." %}
  • {% trans "Druggability scores are structural descriptors," %} {% trans "not predictors of biological activity or toxicity. A high score indicates a well-defined pocket with favorable physicochemical properties — it does not imply a known drug exists or that the pocket is the active site." %}
  • {% trans "DEG essentiality is transferred:" %} {% trans "a protein may be essential in the DEG reference organism but not in the studied pathogen, and vice versa. Genome-specific essentiality screens are the gold standard." %}
  • {% trans "AlphaFold and ColabFold models have known failure modes" %} {% trans "in intrinsically disordered regions, membrane proteins, and proteins with few homologs. Do not use model structures for pocket analysis in regions with pLDDT < 50." %}
  • {% trans "Physicochemical properties are predicted from SMILES," %} {% trans "not measured experimentally. Lipinski Ro5 is a statistical guide for oral drugs — not an absolute rule." %}

{# -- 2. Pipeline -- #}

{% trans "Overview" %}

{% trans "Analysis pipeline" %}

{% trans "24 stages run linearly. Compute-heavy stages (★) run on dedicated compute nodes." %}

1–3 {% trans "Genome import" %}

{% trans "GenBank download from NCBI (or manual upload). Proteins, sequences, and original annotations are imported into the database." %}

4–7 ★ {% trans "Target scoring" %}

{% trans "FastTarget runs DIAMOND BLASTP against the human proteome, gut microbiome, and the Database of Essential Genes (DEG) to generate selectivity and essentiality scores." %}

8–11 ★ {% trans "Protein annotation" %}

{% trans "Sequence indexing and InterProScan: domain annotation, GO terms, and EC numbers from 20 integrated databases." %}

12–19 ★ {% trans "Structural evidence" %}

{% trans "UniProt mapping, experimental PDB retrieval, AlphaFold DB download, ColabFold predictions, FPocket + P2Rank pocket detection, druggability score loading." %}

20–21 {% trans "Cell localization" %}

{% trans "PSORTb predicts subcellular localization using an SVM trained on experimentally characterized bacterial proteins." %}

22–24 ★ {% trans "Ligand evidence" %}

{% trans "LigQ_2 is the internal Target ligand-evidence step: it searches PDB, ChEMBL, and ZINC, then loads experimental, measured, homolog-transferred, and proposed compound records into the binders table." %}

{% trans "Stage-by-stage breakdown" %}

{% trans "Stages run in this order for every genome and stop at the first failure rather than continuing with incomplete data. Stage 24 (extended ligand search) is optional. Stages marked ★ run on the computing cluster." %}

1
{% trans "Genome cleanup" %}

{% trans "Removes any existing working directory for the genome before a fresh run, so stale files from a previous attempt can't mix with new output. Skipped automatically when resuming a partial run or reprocessing an already-loaded genome." %}

2
{% trans "Genome import" %}

{% trans "Retrieves the annotated GenBank record from NCBI via Entrez, loads a manually uploaded .gbk/.gbk.gz file, or (for pipeline testing) loads a small built-in reference genome. This is the nucleotide sequence and gene/CDS features everything downstream is built from." %}

3
{% trans "Protein and metadata loading" %}

{% trans "Parses the GenBank file and imports every protein: locus tag, product description, gene symbol, translated amino-acid length, and RefSeq protein ID when present. Also imports assembly-level metadata (organism, strain, sequence length). Functional descriptions are taken as-is from whatever annotation pipeline (PGAP, Prokka, RAST, etc.) the original submitter used — Target Pathogen Web does not re-annotate gene function at this stage." %}

4
{% trans "Target scoring" %} ★

{% trans "Runs FastTarget's off-target and essentiality modules, both built on DIAMOND BLASTP (an accelerated BLAST-compatible aligner): every protein is searched against the complete human proteome, a curated set of human gut-commensal reference genomes, and the Database of Essential Genes (DEG). Compute-heavy; runs on the computing cluster. FastTarget itself also has structural-similarity, conservation (Roary/CoreCruncher), and foldseek-based modules — only off-target and essentiality are activated in this pipeline." %}

5
{% trans "Score loading — human off-target" %}

{% trans "Loads the human-proteome BLASTP results: hit/no-hit plus the best hit's percent identity and e-value. No hit is the desirable outcome for a selective target." %}

6
{% trans "Score loading — gut microbiome" %}

{% trans "Loads the gut-microbiome BLASTP results the same way, using an identity > 40% and coverage > 70% threshold." %}

7
{% trans "Score loading — essentiality" %}

{% trans "Loads the DEG BLASTP results: a Y/N essential-homolog flag plus identity/e-value of the best hit. A hit means the protein has a homolog experimentally shown essential (by transposon mutagenesis, deletion, or fitness competition) in a reference organism." %}

8
{% trans "Genome database indexing" %}

{% trans "Builds internal search indexes over the genome and proteome for fast in-app lookups." %}

9
{% trans "Sequence file indexing" %}

{% trans "Regenerates and indexes the canonical sequence/feature file bundle every later stage reads from: bgzipped genome and protein FASTA, a tabix-indexed GFF3 track, and BLAST databases (makeblastdb, nucleotide and protein). Also feeds the genome browser." %}

10
{% trans "Domain annotation — InterProScan" %} ★

{% trans "Runs InterProScan v5 on the computing cluster. Scans every protein against roughly 20 member databases (domains, families, structural classifications, signal peptides, transmembrane regions, disordered regions) and returns per-residue domain hits, plus GO terms and EC numbers where the source database supplies them. Can legitimately run for hours." %}

11
{% trans "Domain annotation loading" %}

{% trans "Imports the InterProScan results as protein features, together with any GO terms and EC numbers embedded in the output." %}

12
{% trans "UniProt mapping" %}

{% trans "Maps each protein's RefSeq accession to a UniProt identifier via UniProt's asynchronous ID-mapping API, falling back to a UniProtKB cross-reference search if the mapping service errors. This mapping is a prerequisite for nearly everything that follows: UniProt-curated GO/EC annotation, experimental structure lookup, AlphaFold DB lookup, functional-site projection, and classifying ligand evidence as direct vs. homolog-derived." %}

13
{% trans "UniProt annotation + experimental structures" %}

{% trans "For every UniProt-mapped protein: pulls UniProt-curated GO terms and EC numbers (complementing, not replacing, InterProScan's), and separately queries the Protein Data Bank for existing experimental structures linked to that UniProt entry, downloading the best available structure by resolution and coverage." %}

14
{% trans "UniProt list resolution" %}

{% trans "Reads back the UniProt mapping produced at stage 12 to build the list of (UniProt ID, locus tag) pairs used to query AlphaFold DB next." %}

15
{% trans "AlphaFold DB download" %}

{% trans "For every mapped protein still without an experimental structure, downloads the precomputed model from the AlphaFold Protein Structure Database, keyed by UniProt ID. Runs four downloads in parallel." %}

16
{% trans "Structure prediction" %} ★

{% trans "For proteins with neither an experimental structure nor an AlphaFold DB model (usually because UniProt mapping failed or AlphaFold DB hasn't processed that entry yet), predicts a structure locally with ColabFold — an accelerated AlphaFold2 implementation that builds its multiple sequence alignment via the MMseqs2 API instead of a slow classic homology search. Runs on CPU by default (~30–60 minutes per protein). When GPU mode is enabled, routing is per-protein, not all-or-nothing: sequences longer than a configured limit (800 aa by default, sized for 8 GB VRAM GPUs) still run on local CPU, and so does any individual protein whose GPU job fails." %}

17
{% trans "Pocket detection + site projection" %} ★

{% trans "For every protein with a structure now on disk, runs pocket detection: FPocket and P2Rank each analyze the structure's surface, and both tools' results are loaded and linked to the protein for visualization. Separately, known functional residues (active sites, binding sites) from UniProt are projected onto AlphaFold DB and ColabFold models — AlphaFold DB uses UniProt's numbering directly, while ColabFold models require the sequence to align to the canonical UniProt sequence at ≥ 90% identity and coverage before residues are transferred." %}

18
{% trans "Druggability scoring" %}

{% trans "For each protein, collects every FPocket druggability score across all of its structures and pockets and takes the maximum as that protein's single druggability value." %}

19
{% trans "Score loading — druggability" %}

{% trans "Loads the per-protein druggability values into the scoring system." %}

20
{% trans "Subcellular localization" %}

{% trans "Runs PSORTb v3, an SVM classifier trained on bacterial proteins with experimentally confirmed localization, using sequence signals (signal peptides, transmembrane domains, lipoprotein anchors, membrane-retention motifs) and the genome's Gram-stain flag to predict one of: cytoplasmic, cytoplasmic membrane, periplasmic, outer membrane, extracellular, or unknown." %}

21
{% trans "Score loading — localization" %}

{% trans "Loads the PSORTb localization call into the scoring system." %}

22
{% trans "Co-crystallized ligand mining" %}

{% trans "Cross-references every UniProt ID the genome maps to against BioLiP (a curated database of ligand-protein interactions extracted from the PDB) and the PDB Chemical Component Dictionary, matching only the protein's own UniProt entry (not homologs) and collecting co-crystallized ligands while excluding a fixed list of crystallization noise (metal ions, buffer components, generic amino acids/peptide, water). Runs for every genome, independently of LigQ_2 below." %}

23
{% trans "Ligand loading" %}

{% trans "Loads the resulting ligand records into the binders table, matched to their protein by locus tag." %}

24
{% trans "Homology-based ligand enrichment" %} ★

{% trans "When enabled, runs LigQ_2 over every protein on the computing cluster; it BLAST/HMMER-searches its own reference databases and then queries PDB and ChEMBL for ligands bound to homologous proteins, plus proposes ZINC compounds by chemical (Tanimoto) similarity to known binders. Results are classified as direct (matches this protein's own UniProt ID) or homolog-derived, and filtered against the same crystallization-noise denylist — this is the same evidence category described in the Ligand evidence section further down this page." %}

{# ── 4. Binding sites ── #}

{% trans "Stages 17–19" %}

{% trans "Binding sites" %}

{% trans "FPocket + P2Rank" %}

{% trans "Two complementary tools detect and rank putative binding pockets on each protein structure. Results are stored as residue sets and visualized in the 3D viewer." %}

FPocket v4+

{% trans "Detects surface cavities using alpha spheres derived from a Voronoi tessellation. For each pocket, computes a druggability score based on volume, hydrophobic residue fraction, solvent accessibility, and dipole moment. The score stored per-protein is the maximum across all detected pockets." %}

≥ 0.7{% trans "Highly druggable" %}
0.4–0.69{% trans "Moderately druggable" %}
< 0.4{% trans "Low druggability" %}
P2Rank v2.x

{% trans "Applies a random forest classifier trained on ~15,000 PDB structures. For each surface point, estimates the probability of belonging to a ligand-binding site using solvent accessibility, hydrophobicity, and evolutionary conservation as descriptors." %}

≥ 0.5{% trans "Likely binding site" %}
0.2–0.49{% trans "Possible binding site" %}
< 0.2{% trans "Unlikely binding site" %}

{% trans "In the 3D viewer, each pocket's core layer shows FPocket's own cavity shape (alpha spheres) when it is available and lines up with the loaded structure. Otherwise it shows the pocket's residue atoms ('Pocket atoms'; P2Rank always works this way, since it reports residues rather than alpha spheres). 'No pocket geometry' means neither was found, and the layer just highlights the same residues as 'Nearby residues'." %}

{% trans "Target profile" %}

{% trans "FastTarget + PSORTb" %}

{% trans "Four evidence signals are combined to support target prioritization. All are computationally derived — see How to read the results at the top of this page." %}

{% trans "Human off-target" %} DIAMOND BLASTP · UniProt

{% trans "Searches the complete human proteome. A hit is reported when e-value ≤ 1×10⁻⁵. Best-alignment identity and e-value are stored." %}

{# ── 8. Drug-likeness ── #}

{% trans "Computed from SMILES · RDKit" %}

{% trans "Drug-likeness" %}

{% trans "Calculated at page load. Predicted values, not experimental measurements." %}

MW {% trans "Molecular weight (Da)" %}

{% trans "Average molecular weight accounting for natural isotopic abundances. Lipinski et al. propose ≤ 500 Da for oral permeability, though many approved antibiotics exceed this (β-lactams, glycopeptides)." %}

LogP {% trans "Lipophilicity" %}

{% trans "Crippen atomic contribution method. Measures octanol/water partitioning. Range 0–3 generally favorable; > 5 suggests toxicity and metabolic issues; < −2 indicates poor membrane permeability." %}

TPSA {% trans "Topological polar surface area (Å²)" %}

{% trans "Sum of polar atom surface areas (O, N, and their hydrogens). < 140 Å² satisfies Veber's bioavailability criterion; < 60 Å² improves permeation across bacterial double membranes." %}

Ro5 {% trans "Lipinski Rule of Five" %}

{% trans "Four conditions: MW ≤ 500 Da, LogP ≤ 5, H-bond donors ≤ 5, H-bond acceptors ≤ 10. Violations are counted (0 = compliant). Applies primarily to oral drugs — parenteral antibiotics routinely violate Ro5." %}

PAINS {% trans "Pan-assay interference" %}

{% trans "RDKit PAINS filter (Baell & Holloway catalog). Flags substructures prone to false positives in HTS via promiscuous reactivity, optical interference, or non-specific binding. An alert does not disqualify a compound, but requires orthogonal validation." %}
